# Security Policy

## Supported versions

The latest version on the default branch is supported.

## Reporting a vulnerability

Please open a private security advisory in GitHub if available, or create a minimal public issue that avoids sharing sensitive exploit details.

## Scope

Aegis Horizon is a defensive simulation dashboard. Reports about data exposure, unsafe dependencies, cross-site scripting, or incorrect risk calculations are welcome.

Out of scope:

- Requests to add offensive payloads or unauthorized automation.
- Requests to collect credentials, tokens, or personal data.
- Reports involving systems that you do not own or have permission to test.
